# 玩法规则说明

## 1. 正常模式
标准中国象棋。红先黑后；将/帅被将军必须应将；**无子可动（困毙）判负**；将帅不可照面（飞将）。

## 2. 揭棋
- 开局：帅/将固定在本方九宫原位并且是明子；本方其余 15 枚棋子的**身份随机洗牌**，分别放在本方其余 15 个初始格上，全部**背面朝上（暗子）**。
- **双方都看不到暗子的身份**（包括自己的暗子），**也看不到它的阵营** —— 暗子背面纹样统一，协议里 `color` 为 `null`，只有翻开之后才知道是红是黑。
- 暗子的走法由它**所在初始格的位置角色**决定：在"车"位就走车步，在"马"位就走马步，在"炮"位就走炮步，在"兵"位就走兵步，在"士/象"位就走士步/象步。
- 暗子**一移动就翻开**，之后按它的真实身份行棋。
- 暗子被吃时先翻开、再移除，双方都看到它到底是什么。
- 将/帅是明子，因此将军、应将、绝杀（含困毙）与正常模式一致。
- **被翻开的象/相可以过河**（仍走"田"字、仍会被塞象眼）；还没翻开的暗子不能过河。
- **被翻开的士/仕、将/帅不再受九宫限制**，但步法不变：士仍走一步斜线、将仍走一步直线。开局就是明子的将/帅依旧只能待在九宫。

## 3. 全乱揭棋
- 开局：**红黑 32 枚棋子（连颜色一起）整体打乱**，铺满 32 个初始格。所以**阵营也是乱的** —— 红方底线上完全可能站着黑子，黑方底线上也可能站着红子。
- 全部背面朝上。暗子走法同上：按所在初始格的位置角色走；移动即翻开，之后按真实身份走。
- 因为连将/帅在哪都不知道：
  - **将/帅被吃 = 立即判负**；
  - 只有**已经翻开的**将/帅才会被将军、才受"不能送将"的约束；
  - 将/帅翻开后若被绝杀（无合法着法），同样判负。
- 同样适用：**翻开的象可过河**；**翻开的士/将不受九宫限制**（将若一开始就被洗到九宫外，翻开后即可自由行走）。
- **翻开之前连阵营都不知道**：暗子的颜色不下发，红/绿描边也不会标注暗子（否则等于泄露阵营）。

## 4. 全明乱棋（"一开始就揭完的全乱揭棋"）
- 布局与全乱揭棋完全相同（同样是**红黑混置的乱阵营**），但**开局即全部翻开**。
- 按正常象棋规则行棋、将军、绝杀，另外**象/相可以过河**。
- 士/将若被洗到九宫外，同样解除九宫限制（否则它一步都走不了）。

## 5. 长将判负 / 重复局面
同一局面（含该谁走）第 3 次出现时：
- 若此时轮到的这一方**正被将军** → 说明对方在连续将军，**长将方判负**（被将一方获胜）；
- 否则判**和棋**。

只回看最近 40 个半回合。AI 在搜索里把"和棋"记 0 分、把"长将判负"记为输，因此不会再无限循环将军。

## 6. 红/绿描边（安全吃子提示）
某一枚棋子如果**能被对方吃掉、而且对方吃掉它之后不会被任何棋子反吃**（俗称"白吃"），就会显示描边：
- **红色描边**：这是**我方**的棋子，正被对方白吃，赶紧处理。
- **绿色描边**：这是**对方**的棋子，我可以白吃它。

## 7. 胜负
- 吃掉对方将/帅（限暗将模式）→ 胜。
- 对方被绝杀（将军且无着可解）→ 胜。
- 对方被困毙（未被将军但无子可动）→ 胜。
- 对方**长将**（同一局面第 3 次出现且每次都在将军你）→ 判对方负。
- 同一局面第 3 次出现、但双方都没有连续将军 → **和棋**。
- 对方认输 / 掉线超时 → 胜。
