# 玩法规则说明

## 1. 正常模式
标准中国象棋。红先黑后；将/帅被将军必须应将；**无子可动（困毙）判负**；将帅不可照面（飞将）。

## 2. 揭棋
- 开局：帅/将固定在本方九宫原位并且是明子；本方其余 15 枚棋子的**身份随机洗牌**，分别放在本方其余 15 个初始格上，全部**背面朝上（暗子）**。
- **双方都看不到暗子的身份**（包括自己的暗子）。
- 暗子的走法由它**所在初始格的位置角色**决定：在"车"位就走车步，在"马"位就走马步，在"炮"位就走炮步，在"兵"位就走兵步，在"士/象"位就走士步/象步。
- 暗子**一移动就翻开**，之后按它的真实身份行棋。
- 暗子被吃时先翻开、再移除，双方都看到它到底是什么。
- 将/帅是明子，因此将军、应将、绝杀（含困毙）与正常模式一致。

## 3. 全乱揭棋
- 开局：本方 **16 枚**棋子（**包括将/帅**）的身份全部随机洗牌，放到本方 16 个初始格上，全部背面朝上。
- 暗子走法同上：按所在初始格的位置角色走；移动即翻开，之后按真实身份走。
- 因为连将/帅在哪都不知道：
  - **将/帅被吃 = 立即判负**；
  - 只有**已经翻开的**将/帅才会被将军、才受"不能送将"的约束；
  - 将/帅翻开后若被绝杀（无合法着法），同样判负。

## 4. 全明乱棋（"一开始就揭完的全乱揭棋"）
- 布局与全乱揭棋完全相同（本方 16 枚身份随机洗牌到本方 16 个初始格），但**开局即全部翻开**。
- 完全按正常象棋规则行棋、将军、绝杀。

## 5. 红/绿描边（安全吃子提示）
某一枚棋子如果**能被对方吃掉、而且对方吃掉它之后不会被任何棋子反吃**（俗称"白吃"），就会显示描边：
- **红色描边**：这是**我方**的棋子，正被对方白吃，赶紧处理。
- **绿色描边**：这是**对方**的棋子，我可以白吃它。

## 6. 胜负
- 吃掉对方将/帅（限暗将模式）→ 胜。
- 对方被绝杀（将军且无着可解）→ 胜。
- 对方被困毙（未被将军但无子可动）→ 胜。
- 对方认输 / 掉线超时 → 胜。
